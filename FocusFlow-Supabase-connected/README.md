# Focus Flow

아이폰/아이패드에 최적화된 프로젝트·일정·칸반·뽀모도로 웹앱.

## 설치 / 실행

```bash
npm install
npm run dev
```

브라우저에서 제시된 주소를 엽니다. 배포 전 검증: `npm run build`.

## 포함 기능

- 프로젝트 목록, 프로젝트별 할 일, 하위 작업, 날짜/시간 지정
- 개인 일정(프로젝트 없이 등록 가능)
- 오늘의 할 일 칸반(드래그 이동 가능), 완료 기록
- 오늘을 지나도 완료되지 않은 할 일 자동 표시(원래 예정일 보존)
- 월간/주간/3일/1일 캘린더, 프로젝트 색상 구분
- 오늘의 할 일을 선택해 25분 집중/5분 휴식, 집중 회차 기록
- localStorage에 브라우저별 자동 저장

## 주의

첫 버전은 서버 없이 동작합니다. **iPhone/iPad 기기간 동기화, 계정 로그인, 푸시 알림, 반복 일정, 백그라운드 타이머 실행 보장**은 아직 구현되지 않았습니다. 브라우저 데이터를 지우면 기록이 사라질 수 있습니다.
