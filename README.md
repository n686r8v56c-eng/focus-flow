# Focus Flow v5

프로젝트·투두·서브태스크, 세로형 오늘 칸반, 월간/주간/3일/1일 일정, 뽀모도로 타이머와 통계.

```sh
npm install
npm run build
npm run dev
```

뽀모도로: 시작/일시정지/정지, 초침 3종/미리 듣기/ON·OFF, 완료 알림. 완료한 25분 집중 세션만 기록하며 중단·휴식 시간은 집중 통계에 포함하지 않습니다. 투두를 삭제해도 집중 기록은 유지합니다.

통계: 총/최근 7일/오늘 집중 시간, 오늘 시간대별 완료 기록, 일일 목표와 월간 달성 캘린더, 일일/주간/월간/연간 그래프. 날짜는 기기 현지 시간 기준입니다.

기존 Supabase 로그인과 사용자별 저장을 유지합니다. 다른 기기의 변경은 포커스 복귀 및 12초 간격으로 확인합니다. 서로 다른 항목 변경은 병합하며 같은 항목의 충돌은 경고하고 저장을 중단합니다. 저장 전 변경은 사용자별 기기 임시 보관함에 남깁니다. 브라우저 데이터를 지우기 전 동기화 완료 여부를 확인하세요.

실행 중 타이머 자체는 기기 간 공유되지 않습니다. 프로젝트·투두·서브태스크·완료 집중 기록과 설정이 동기화됩니다. 모든 열린 기기를 최신 버전으로 새로고침해야 개선된 동시 저장 보호가 적용됩니다.

현재 라이브 RLS 정책 검증과 실제 iPhone/iPad 오디오·동기화 검증은 별도로 필요합니다. 저장소의 `supabase.sql`은 사용자별 SELECT/INSERT/UPDATE 제한을 정의하며 기존 테이블을 업데이트할 필요는 없습니다.
